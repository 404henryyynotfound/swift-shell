Get started

Up and running in one command

Pick your package manager. The CLI is a single binary with no runtime to babysit.

npm 
npm install -g swift-shell

Works anywhere Node.js is installed.

apt 
curl -fsSL https://github.com/404henryyynotfound/swift-shell/releases/latest/download/swift-shell_1.0.0_amd64.deb -o swift-shell.deb
sudo apt install ./swift-shell.deb

Grabs the latest .deb from GitHub Releases.

snap 
sudo snap install swift-shell

Confined, auto-updating, and easy to remove.

Language tour

Familiar ideas. Cleaner syntax.

Explore the pieces that make everyday scripting feel effortless.

variables.shSwiftShell
# Names, values, and collections
let name = "world"
let counts = [1, 2, 3]

echo "Hello, " + name
echo len(counts)  # → 3
functions.shSwiftShell
# Define once, call anywhere
func greet(who) {
  echo "Hi, " + who
}

let shout = { text in upper(text) + "!" }
echo shout("swift")
pipeline.shSwiftShell
# Unix tools are first-class citizens
cat notes.txt \
  | grep "todo" \
  | wc -l > count.txt

echo "-- updated --" >> count.txt
control.shSwiftShell
for i in range(1, 4) {
  if i % 2 == 0 {
    echo upper("even " + i)
  } else {
    echo "odd " + i
  }
}

Why SwiftShell

Everything a script needs. Nothing it doesn't.

Small enough to learn in an afternoon, expressive enough to keep using for years.

Variables & arrays

Inferred let bindings and first-class arrays. Store data once and use it everywhere without boilerplate.

Functions & closures

Name a block with func, or write a compact closure inline and pass it around like any other value.

Pipelines & redirection

|, >, and >> are part of the language, so composing commands reads naturally.

Loops & conditionals

Readable for … in loops, if/else, and familiar comparison operators with real block scope.

Real Unix commands

Call grep, curl, jq, or anything on your PATH directly — no wrappers or escaping.

Friendly errors

Line numbers, clear messages, and helpful hints instead of a wall of cryptic interpreter output.
